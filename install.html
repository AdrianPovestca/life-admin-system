Install Punctlife

Punctlife is a web application. You can install it on your device for a faster, full-screen experience.

Note: Installation availability depends on your browser. PWA installation is currently being rolled out. If you don't see the option, you can always use Punctlife directly in your browser.

iPhone & iPad (Safari)

  1. Open app.punctlife.com in Safari.
  2. Tap the Share button (the square with an arrow pointing up).
  3. Scroll down and tap Add to Home Screen.
  4. Tap Add in the top right corner.

Android (Chrome)

  1. Open app.punctlife.com in Chrome.
  2. Tap the three dots in the top right corner.
  3. Tap Add to Home screen or Install app.
  4. Follow the on-screen prompts.

Desktop (Chrome or Edge)

  1. Open app.punctlife.com in your browser.
  2. Look for the install icon in the address bar (a small monitor with an arrow).
  3. Click it, then click Install.
  4. If you don't see the icon, click the three dots menu and select Install Punctlife.
